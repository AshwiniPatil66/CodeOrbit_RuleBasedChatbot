# Rule-Based Chatbot

## Description
A simple chatbot developed using Python.
It responds to user messages using predefined
rules and conditions.

## Technologies Used
- Python
- VS Code

## Features
- Greeting responses
- Answers common questions
- Thank-you response
- Unknown input handling
- Exit command

## How to Run
1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run: python chatbot.py
